# Project Summary
## Name
API Testing Portfolio Project

## Type
Automated API test framework

## Primary objective
Show practical QA automation skills using `pytest`, `requests`, schema validation, and CI.

## Key implementation highlights
- Reusable API client abstraction (`src/api_client.py`)
- Session fixture with retry strategy for transient errors
- Parametrized tests for broader endpoint validation
- Contract-style schema validation (`jsonschema`)
- Smoke and contract markers in pytest
- Multi-version CI (Python 3.9–3.12)

## Result
A clean, reproducible, and recruiter-friendly API automation portfolio project.
